## Highlights

### "Load from base pattern" fills the Sample column on client sheets
- Feature request (pattern account hagan.dp1@gmail.com) on the client
  pattern measurement sheet (e.g. TROUSER-S05005 / Abdallah Al Luwaihiq):
  a button to pick a base pattern + size and duplicate those measurements
  into the SAMPLE column instead of typing them by hand.
- New "Load from base pattern" button on the Sample / Trials / Final sheet
  toolbar (`ClientPatternDetail`), next to Save sheet. Opens a picker modal
  (`LoadFromBaseModal`): searchable base list defaulting to the sheet's
  garment type (checkbox widens to all garments), then a column choice -
  every size on the base, plus the client's fit column (`client_columns`,
  shipped `7a56dfc`) when that base has one for this client. The fit
  column is preselected when present; otherwise the sheet's derived size.
- Units convert between the base grid and the sheet: cm -> inches snaps to
  1/16" (sheet precision, matches `formatMeasurement`); inches -> cm keeps
  2 decimals; same unit copies untouched. The modal shows a conversion
  note when the units differ.
- Measurement point matching (`src/lib/pattern-library/load-from-base.ts`,
  pure helpers): point_id equality, then normalized-name (case / spacing /
  punctuation-insensitive), then dictionary aliases (both directions), then
  a unique-containment token pass ("1/2 Waist" -> "1/2 Waist straight
  Relux"). Each base point is claimed once; ambiguous rows (e.g. generic
  "Front Rise" when the base has incl./excl. w/b variants) stay empty. The
  modal previews "N of M points will fill" and the result notice lists the
  unmatched names so the operator knows what to enter by hand.
- The copy is client-side into the editable Sample cells (`base_value`
  across trials, same cells as manual Sample edits); persisting goes
  through the existing Save sheet flow (PATCH versions endpoint). No new
  write path, so no new /api/v1 route or Zapier event was needed; the
  existing `client_pattern.updated` fires on save. Pattern operators
  already have access (page + `/api/pattern/library` GET are allowlisted).
- Verified locally on TROUSER-S05005 against Massimo Cotton Trouser 0002
  (cm grid): 22 of 57 points filled, 55.5 cm -> 21 7/8", fractions render
  correctly in the Sample inputs; test fill discarded without saving.
- Tests: `npm run test:load-from-base` (14 cases - conversion rounding both
  directions, normalization, alias/containment/ambiguity/claim rules,
  client-column fallback to its anchor size, full fill run with summary).
