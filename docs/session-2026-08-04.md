### Quality Control "+ New Inspection" now actually opens and saves
- Bug (QC Hossein, hagan.qc@gmail.com): clicking "+ New Inspection" on
  `/quality` did nothing. Root cause: the button was a static server-rendered
  placeholder - no onClick, no dialog, no API. The whole create-inspection
  flow had never been built (stub page). Not a permission issue: `/quality`
  was already allowed for client_manager; there was simply nothing behind
  the button, for admin too.
- Built the real flow following existing app patterns:
  - `NewInspectionButton` client dialog (date, optional work order picker
    fed from production work orders, sample size, pass/rework/fail, notes)
    with inline error surfacing; refreshes the page list on save.
  - Persistence via a new `quality_inspections` ERP document
    (`src/data/quality-inspections.json` + Supabase `erp_documents`),
    store in `src/lib/data/quality-inspections.ts`.
  - Session API `POST/GET /api/quality/inspections` (admin + QC +
    factory manager may create; clear 403 message otherwise) and Zapier
    parity route `POST/GET /api/v1/quality-inspections` (API key auth).
    New outbound event `quality_inspection.created` (types + ZapierSetup).
  - `/api/quality` added to client_manager and production_operator route
    allowlists; `getQualityInspections()` now reads the document store and
    merges any legacy Supabase table rows.
  - The quality page table shows the human work-order label (sticker code /
    client / garment) instead of `WO-<id>`.
- Tests: `npm run test:quality-inspections` (permission matrix + input
  validation + record stamping) and new `npm run test:permissions` script
  for the existing permissions suite, extended with `/api/quality`
  allow/block assertions (QC + factory manager allowed; pattern,
  accounting, sales blocked).
- Verified end-to-end locally as impersonated QC: dialog opens, work order
  attaches, save persists (201), page stats/table update; sales operator
  gets 403 from middleware. Test records were removed from the shared
  Supabase document afterwards.
